# Superstore Profit Analysis

Google Sheets project: clean data, pivot tables, charts, and findings.

## Main finding
West has the highest total profit. Central has the lowest.

Central is weak because Furniture loses money there. West Furniture is profitable.

Central Furniture average discount is about 30%. West Furniture is about 13%.

## Files
- Excel workbook with data, two pivots, two charts, and a findings tab
- CSV backup of the cleaned data

## How I did it
1. Cleaned the sheet (copy, trim, duplicates, formats)
2. Pivot: profit by region
3. Pivot: Furniture profit by region
4. Compared discounts for Central vs West Furniture
